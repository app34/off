# Off Days

Mobile PWA for roster off, annual leave, medical, and other leave.

## GitHub Pages

1. Create a repository.
2. Upload every file in this folder to the repository root. Keep the `icons` folder.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Open the Pages URL on your phone and use Add to Home Screen.

Admin stays hidden. Tap anywhere five times within three seconds to unlock it. Export and import live inside Admin. All day marks stay in the phone's local storage.
